# 未启用对比项

- **任务随机调度**：用随机任务顺序替代每个 visit 固定的 Maze → 4Rooms 顺序。
- **一次性视觉预训练**：先完成全部世界模型训练并冻结，再集中进行好奇心探索，替代逐任务交替训练。
- **随机动作采集**：使用均匀随机策略采集世界模型数据，替代带视觉编码器快照的固定 CTM。
- **采集策略实时变化**：让采集策略使用正在更新的编码器，替代固定视觉快照。
- **历史条件预测器**：用观测历史或循环状态预测下一表示，替代单帧表示输入。
- **均匀历史回放**：均匀保留和采样探索数据，替代优先使用高预测误差数据。
- **跨任务混合回放**：训练当前任务的世界模型时加入另一任务的数据，以研究世界模型的遗忘。
- **探索期间继续更新预测器**：保持编码器冻结，但让预测器随探索数据更新，替代整个世界模型冻结。
- **世界模型与策略联合训练**：同时更新视觉编码器、预测器和 CTM，替代分阶段冻结与优化。
- **同任务轮次间保留 Active**：蒸馏后继续训练原 Active，替代下一轮重置。
- **任务切换时随机初始化控制器**：保留共享 ResNet，仅随机初始化 Active 控制器和输出头，替代从 KB 复制。
- **仅复制 KB 控制器**：继承 KB 的内部处理模块，但重新初始化 Actor–Critic 输出头。
- **任务切换时直接延续 Active**：继续使用上一任务的 Active 参数，替代用 KB 参数覆盖。
- **独立视觉 backbone**：为 KB 和 Active 分别保留独立 ResNet，替代共享编码器。
- **仅保留部分 CTM 作为 KB**：只保留 Synapse/NLM 等核心模块，替代完整控制器知识库。
- **P&amp;C 阶段继续适应视觉**：允许后续任务更新 ResNet，替代任务无关阶段结束后永久冻结。
