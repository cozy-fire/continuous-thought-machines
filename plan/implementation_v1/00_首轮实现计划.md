## 2. 目标与首轮边界

实现一个跨 2D Maze（mazes-medium）和 MiniGrid 4Rooms 的持续学习系统。策略通过单帧 RGB 和自身循环状态决策；Task-Agnostic 先学习视觉动力学表示及探索策略，随后使用外在奖励执行 P&C。最终 KB 必须能在两个任务上独立执行，不依赖 Active、环境任务 ID 或任务专用策略头。

首轮要验证三件事：

1. 两类环境使用相同像素、动作和循环策略接口。
2. 各阶段损失只更新约定模块，序列状态、超时 bootstrap、教师冻结和 EWC 的实现正确。
3. 能分别测量 Active 的学习速度与 KB 的跨任务成功率和遗忘；不预先承诺性能提升。

不启用：随机任务调度、历史条件世界模型、跨任务混合回放、实时更新采集策略、探索期间更新世界模型、PPO/视觉联合训练、从 KB 初始化 Active、仅核心 KB、主方法的独立双视觉 backbone、P&C 期间继续更新主方法视觉。未列入首轮的消融不得由实现 agent 自行加入。

本轮实现与基线的正式训练是后续工作；不能因文档列出训练预算而自动租用机器、启动完整训练或修改已有实验。

## 3. 已确定的系统设计

| 子系统 | 首轮行为 | 来源 |
|---|---|---|
| 观察 | 单帧 uint8 RGB，CHW 3×84×84；模型入口转 float32 并除 255；无帧堆叠 | 用户决策；数值格式为工程默认 |
| 视野 | Maze 全图；4Rooms 原生受遮挡的 7×7 局部视野转 RGB | 用户决策 |
| 视觉风格 | 保留两环境各自原生颜色和形状 | 用户决策 |
| 动作 | Discrete(5)，Maze=上/下/左/右/等；4Rooms=左转/右转/前进/等/等 | 用户原设想 |
| 环境信息 | task 名称仅供环境适配、调度、日志与数据过滤；不输入网络 | 用户决策 |
| 外在奖励 | 普通步 0；成功时 1−0.9×step_count/300；最多 300 步 | 用户决策 |
| 视觉 backbone | 本地 CTM 的 resnet34-2，随机初始化；不是 torchvision 标准 7×7 stem | 用户规格；初始化沿用 CTM |
| 位置编码 | Attention 的 Q/K 使用二维 axial RoPE | 用户选择 RoPE；具体形式为工程默认 |
| CTM | 每环境步 2 ticks；D=512；NLM 与两种同步窗口 M=20 ticks | ticks/M 为用户决策；D 为工程默认 |
| KB/Active | 共享视觉特征；各自完整 Attention、CTM、同步读出、Actor；Active 有当前阶段 Critic | 用户决策；KB 不保留无监督的 Critic 为工程默认 |
| 侧向连接 | 每 tick：先推进 KB，投影其新激活，再加入 Active 的 Synapse 输入 | 用户选择 tick 内连接；精确接法为工程默认 |
| 世界模型 | E→全局平均池化→MLP g→动作条件 MLP F；单帧预测 | 用户决策 |
| 视觉目标 | 平方误差预测损失 + SIGReg；两端均反传，无 EMA/stop-gradient 目标 | 用户选择预测+SIGReg；精确损失为工程默认 |
| 探索目标 | 固定世界模型下的 log(1+未平方 L2 预测误差)，无外在奖励混入 | 用户主流程 |
| 蒸馏 | 冻结教师采样；沿序列只蒸馏动作 KL；Online EWC 保护 KB | 用户决策 |
| Fisher | 对 KB 策略 log-prob 的逐样本梯度平方求平均，不使用 reward/value/advantage | 用户决策 |

## 4. 总体执行顺序

```text
初始化 E、g、F、KB；高误差池按任务隔离且为空
for agnostic_visit in 0..5:
    for task in [maze_medium, fourrooms]:
        for round_in_task in [0, 1]:
            世界模型 W：冻结 E_old+KB 的采集快照 → 采集当前任务 → 训练 E/g/F
            探索 X：冻结 E/g/F/KB → 随机初始化 Active/Adapter/Critic → PPO 内在奖励
            蒸馏 C：固定 E/g/F 和教师全部依赖 → KL+EWC 更新 KB
            无奖励 Fisher：采集 KB 轨迹 → 更新重要性与 KB 参数中心
冻结最终 E 及 BatchNorm buffers；保存视觉基准 checkpoint
for pnc_visit in 0..2:
    for task in [maze_medium, fourrooms]:
        Progress P：重置 Active/Adapter/Critic/优化器 → PPO 外在奖励
        Compress C：冻结教师 → KL+EWC 更新 KB → 无奖励 Fisher
```

世界模型采集与离线训练均归属 W 阶段，但先完成采集再更新视觉参数。采集快照在整个 W 阶段不变。首轮的采集控制器使用随机初始化的 KB，之后使用上轮蒸馏后的 KB；不使用刚随机初始化的 Active 作为后续轮次采集器。

每个阶段开始时显式重置环境与循环状态；自然 episode 内保留状态。阶段边界仅用于调度，不伪装成环境失败或提供额外任务输入。

## 5. 必须保留的解释边界

### 5.1 共享视觉在预训练期间会改变 KB 行为

W 阶段只冻结 CTM/Actor 权重，不代表 KB 的完整函数不变：共享 E 更新后，同一图像的特征可能改变。采集快照只保证采集行为稳定，不能消除当前 KB 在新 E 下的行为变化。

首轮遵照用户选择允许该阶段间变化，不增加旧视觉常驻分支、跨任务混合回放或特征对齐损失。每次 W 前后都评估 KB，报告变化；EWC 不约束 E，不能声称它保护了视觉表示。Task-Agnostic 结束后 E 固定，该漂移来源才停止。

### 5.2 时间窗口与重放

M=20 指内部 ticks；2 ticks/环境步，因此蒸馏 burn-in 明确为 10 个历史观察的完整策略前向（20 ticks）。这是本计划对“预热长度与 M 一致”的单位解释，不是 20 个环境步。有限 burn-in 是对更长循环依赖的近似，不保证精确重建任意历史状态。

### 5.3 动作含义与奖励

5 个输出槽仅统一维数；两个任务的动作语义不同。4Rooms 的两个等待槽均保留，不 mask、不合并 KL 概率。9 是适配器哨兵，不传给 MiniGrid.step 或网络 one-hot。

目标在 task-agnostic 阶段仍可见，到达目标仍终止；严格的“无外在奖励”指训练损失和 Fisher 不读取外在 reward，不表示环境完全无目标语义。

### 5.4 验证范围

只有两个任务域，且均参与 Task-Agnostic。结论限定为这两个任务域内的学习与知识保持；独立测试地图不等于未见任务域。单帧世界模型在局部观察下可能存在不可约预测误差；高误差不必然等于可学习的新颖性。

## 7. 审阅重点

以下为明确工程默认，接受本稿即固定为首轮实现值：

- ResNet 随机初始化；D=512、Attention 4 heads×32、投影维度 128；RoPE 全局 query 固定在特征图中心。
- SIGReg 使用 ECF 数值积分，256 directions、17 knots、lambda=0.02；预测损失使用维度平均 MSE，奖励仍用未平方 L2。
- 每任务只保存最近一次探索的高误差 top-50,000 转移；W minibatch 新采集/高误差数据按 1:1 混合，没有高误差数据时全用新采集。
- 每阶段重置环境；Teacher/KB/Active 独立循环状态；蒸馏用 10 个环境观察 burn-in+50 个学习步。
- 首轮只支持单设备；正式 num_envs=8、PPO rollout=50；运行模式和全量预算详见 02。
- checkpoint 只允许在阶段边界做精确恢复；不承诺跨任意环境步的逐位续训。

上述初值是可审阅、可复现的起点，不是已验证的最优超参数。
