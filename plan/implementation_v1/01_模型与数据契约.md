| h,dh | Attention heads 与每头维数 | 4,32 |

## 2. 环境与图像

### 2.1 对外统一接口

单环境遵循 Gymnasium：`reset(seed) -> (obs, info)`，`step(action) -> (obs, reward_ext, terminated, truncated, info)`。

- `obs`: NumPy uint8 `[3,84,84]`，RGB 顺序，连续内存。
- `action`: Python int，满足 0≤action<5；违反范围直接报错。
- `reward_ext`: float，普通步 0，成功步 `1-0.9*step_count/300`。
- `step_count` 在执行动作时先加 1；成功允许发生在第 300 步，成功优先于超时。
- `terminated=True` 仅表示成功；达到 300 步但未成功时 `truncated=True`。二者不同时为 True。
- `info` 可带 task_key、episode_id、success、episode_step、原始返回值、评估统计；不能拼接到网络输入。
- 无 frame-skip、动作重复、历史堆帧、reward normalization、reward clipping；不使用原 CTM RL 的 NormalizeReward wrapper。

模型唯一输入预处理：`obs.float()/255`；不做 ImageNet mean/std，不扩展为 [-1,1]。训练、采集、蒸馏和评估共用同一个预处理函数。

### 2.2 Maze

- task_key=`maze_medium`。数据根目录 `data/mazes/medium`，仅收录 `train/0/*.png` 与 `test/0/*.png`；不能递归混入 split 根目录的 PNG。
- 原始 RGB 19×19；黑墙、白通路、红起点、绿终点。加载时蓝色答案路径先变为白色；不把答案动作序列存进训练 transition。
- 每张地图必须恰好一个起点和一个终点，路径可达；不符合就报错并列出文件名，不静默换图。
- 每 episode 从当前 split 均匀有放回抽一张图，沿用原起终点。首轮不旋转、不翻转、不重采样起终点。
- agent 每步在原始 19×19 网格移动 1 格：0=(-1,0)、1=(1,0)、2=(0,-1)、3=(0,1)、4=(0,0)，坐标为(row,col)。墙和越界使位置不变，也消耗一步；不额外扣分。
- agent 离开时恢复通路；目标格永久保留绿色。普通位置渲染红色 agent；成功的 final observation 将目标格渲染红色表示当前位置，逻辑 goal 坐标仍不变。无路径尾迹。
- 原始地图使用最近邻放大到 84×84，再 HWC→CHW；不做双线性混色。
- 环境只返回图像；当前坐标、目标坐标、最短路径等不得作为策略或好奇心输入。

### 2.3 FourRooms

- task_key=`fourrooms`。`MiniGrid-FourRooms-v0`，原生 19×19 布局，max_steps=300。
- 使用 `RGBImgPartialObsWrapper(tile_size=8)` 后取 image；得到 56×56×3 的局部 RGB，保留原 7×7 视野、朝向关系与墙体遮挡。
- 56×56 使用最近邻变为 84×84，再 HWC→CHW；无全局地图、mission 文本、direction 数值输入。
- 0/1/2 原样交给 MiniGrid，含义为左转/右转/前进。
- 3/4 都由适配器记为 sentinel=9，再执行原生 action=6（done 的 no-op 分支）；绝不调用 `env.step(9)`。验证实际位置、方向不变且 step_count+1。
- 网络及世界模型保留 3、4 两个不同动作索引，不合并概率、不设置 action mask。两个索引的行为都等效等待。
- 使用原生随机布局、门洞、起点、朝向和目标生成；训练/eval seed 范围按 02 隔离。

### 2.4 向量环境与 episode 边界

首轮使用固定数量 SyncVectorEnv 或等效同步列表实现，必须通过本节统一返回结构；默认不启动子进程。vector adapter 负责处理 autoreset 差异，学习器不依赖 Gymnasium 的隐式 final_observation 字段名称。

`EnvStep` 字段：

| 字段 | 形状/类型 | 含义 |
|---|---|---|
| `next_obs` | uint8 `[B,3,84,84]` | 给下一次策略调用的观察；结束时为 reset 首帧 |
| `transition_next_obs` | 同上 | 本动作后的真实观察；结束时为终止/超时前的 final observation |
| `reward_ext` | float32 `[B]` | 未归一化外在奖励 |
| `terminated,truncated` | bool `[B]` | 分离的结束标志 |
| `next_episode_start` | bool `[B]` | `terminated OR truncated`，下一策略调用之前重置 trace |
| `info` | 长度 B 的字典列表 | 仅日志、存储和环境管理使用 |

环境完成动作后先取得真实 next observation，再 reset 结束的槽位。世界模型、intrinsic reward 和 timeout bootstrap 使用 `transition_next_obs`。不得把新 episode 首帧当作本动作的预测目标。

## 3. 共享视觉与世界模型

### 3.1 ResNet

直接复用本地 `models.resnet.prepare_resnet_backbone('resnet34-2')` 的计算结构：3×3 stride=1 stem、BatchNorm、ReLU、3×3 stride=2 maxpool、ResNet34 layer1/layer2。输入 `[B,3,84,84]`，输出 `[B,128,21,21]`。

- 随机初始化，无预训练权重；不再加原通用 CTM 的输入通道适配 `LazyConv2d(3,1,1)`，因为本接口已固定 3 通道。
- 共享部分仅为 E。KB/Active 各自的 KV 投影、Query 投影、Attention 输出投影不共享。
- `E.train()` 只允许在 W 的梯度更新子阶段。其他阶段须 `E.eval()` 且 `requires_grad_(False)`，固定 BN 的 running_mean、running_var、num_batches_tracked。
- W.fit 开始恢复 E 的梯度；完成时立即 eval/freeze。`encoder_version` 与 `world_model_version` 均初始化为0，仅在一次 W.fit 成功原子提交时各加1；其他阶段不增加版本。W.fit 中的中间权重不对策略阶段发布。
- 首轮只通过 E 编码策略输入，g/F 的输出不得送入 CTM，避免给控制器增加未约定的输入通路。

### 3.2 世界模型网络

`fmap=E(o)`；`p=AdaptiveAvgPool2d(1)(fmap).flatten(1)`，形状 `[B,128]`。

- g：Linear(128,512)→ReLU→Linear(512,128)，最后无激活、无 LayerNorm/L2 normalization、无 BatchNorm。
- 动作：`one_hot(action,5).float()`；不能输入映射后的 9 或 task ID。
- F：concat(z,one_hot(a)) `[B,133]`→Linear(133,512)→ReLU→Linear(512,128)。首轮直接预测 z_next，不使用残差目标。
- 同一 E/g 分别编码 o 和真实 o_next；为统一 BN 统计，W 更新时将两者拼成 `[2B,3,84,84]` 一次编码后拆回。
- W 的两条编码分支均参与反传；不使用 stop-gradient 目标、EMA teacher 或 inverse dynamics。
- g/F 在所有 task-agnostic visits 中连续保留，任务切换不重置；阶段冻结不销毁参数和 optimizer state。

精确损失、SIGReg 和 reward 见 02。注意：预测目标是 pooled 表示，Attention 使用空间 fmap；SIGReg 约束投影表示的边缘分布，不证明空间 tokens 或时序动力学一定无退化。

## 4. Attention 与二维 RoPE

### 4.1 token 和投影

`tokens=fmap.flatten(2).transpose(1,2)` 得 `[B,441,128]`，row-major，token_index=y*21+x。

每列独立执行：

1. `q0=Linear(528,128)(S_action)` 得 `[B,1,128]`。
2. `kv0=LayerNorm(128)(Linear(128,128)(tokens))` 得 `[B,441,128]`。
3. Attention 内部 Wq/Wk/Wv 分别投影 q0/kv0/kv0，reshape 成 `[B,4,1,32]` 与 `[B,4,441,32]`。
4. 对真正用于点积的 Q/K 执行本节 RoPE，然后计算 softmax(QK^T/sqrt(32))V，concat heads 后 Linear(128,128)。

不要仅旋转进入 `nn.MultiheadAttention` 之前的输入，再让不受约束的内部投影改变旋转含义。实现显式 Q/K/V attention 或等价 SDPA 包装。Attention dropout=0，输出 `[B,128]`；跟踪时可返回 weights `[B,4,1,441]`，训练默认不保存完整跟踪历史。

### 4.2 RoPE 规则

首轮使用固定二维 axial RoPE，不使用 learned/mixed frequency 或时间 RoPE。

- 每头 32 维拆成前 16 维 x 轴和后 16 维 y 轴，每轴按相邻两维组成 8 对。
- 对每轴第 j 对（j=0..7），频率 `omega_j=10000^(-2*j/16)`。
- 坐标 p 的旋转角为 `p*omega_j`；旋转 `(u,v)` 得 `(u*cos-v*sin, u*sin+v*cos)`。
- 每个空间 K 使用原 token 坐标 x,y∈[0,20]；不使用实际环境 agent/goal 坐标。
- CTM 的唯一全局 Query 没有对应图像位置，本计划固定其坐标为特征图中心 `(10,10)`。这是工程约定，使点积相对图像中心编码位置；不是从 CTM 论文继承的设计。
- V 不旋转；RoPE 不在 tick/环境步累积，不加入额外 absolute embedding。
- RoPE caches 为不可训练 buffers，保存 theta、坐标生成规则与缓存版本；要求 dh%4=0。

参考：[RoPE-ViT 官方实现](https://github.com/naver-ai/rope-vit/blob/main/models/vit_rope.py)。只复用轴向旋转原理，本计划的单 Query 中心坐标由本项目定义。

## 5. CTM 状态与每 tick 更新

### 5.1 独立状态

`CTMState(pre,post)`：两个 float32 `[B,512,20]` 张量，最后一维从最旧到最新。每列独立拥有可学习的初始 `start_pre/start_post` `[512,20]`，初始化 Uniform(−sqrt(1/(D+M)), +sqrt(1/(D+M)))。

- `initial_state(B)` 将可学习初值展开；不能在模型内部缓存跨 batch 状态。
- episode_start=True 的槽位用各自初值替换，其余槽位原样保留。
- collect 阶段 no_grad；训练重放在 rollout 起点 detach，序列内部不 detach。
- KB、Active、教师所依赖的旧 KB、蒸馏学生均拥有独立 CTMState。不能跨列复制 trace；允许同一个列在快照采样或复算时克隆自己的 state。

### 5.2 同步性

采用 first-last 固定不重叠子集：output 用 `[0,32)`，action 用 `[480,512)`。不用现有 RL 中 output 实际取尾段的行为。

对各子集内部 i≤j 的全部组合，按 `torch.triu_indices(32,32)` 顺序产生 528 个特征。包含自配对。每类有独立可学习 decay_params `[528]`，初始化为 0。

令 u=0..19 为从旧到新索引，`w[u,k]=exp(-(19-u)*clamp(decay_params[k],0,4))`，则：

`S[k] = sum_u w[u,k]*post[i_k,u]*post[j_k,u] / sqrt(sum_u w[u,k])`。

使用当前 post 窗口重新计算，不使用无限累计 alpha/beta。实际存储窗口已含初始化 trace，不另设空历史 padding。clamp 在可微 forward 中完成，不用 `.data` 改写参数。

### 5.3 单列 tick

对当前 post_old：

1. 用 post_old 算 S_action；读取当前 fmap 得 attention_out。
2. 取 `z_prev=post_old[:,:,-1]`。
3. Synapse 输入为 concat(attention_out,z_prev+lateral) `[B,640]`；独立 KB 的 lateral 为零。
4. Synapse：Linear(640,1024)→GLU→LayerNorm(512)→Linear(512,1024)→GLU→LayerNorm(512)。不使用 U-Net。
5. 新 pre 值追加至 pre 窗口，丢最旧项。
6. NLM：每神经元独立 SuperLinear(20,32)→GLU→SuperLinear(16,2)→GLU→squeeze，复用本地 SuperLinear 的权重、bias 和可学习 T 语义；dropout=0，NLM LayerNorm=False。
7. 新 post 值追加至 post 窗口，丢最旧项。

当前观察重复 2 个 tick；不在第二 tick 重新执行 ResNet。只在第 2 tick 后以新 post 算 S_out，输出动作/value。

### 5.4 Actor/Critic

- Actor：Linear(528,64)→ReLU→Linear(64,64)→ReLU→Linear(64,5)，输出 logits。
- Active Critic：同样两层 64 hidden，最后 Linear(64,1)，输出 value `[B]`。
- 沿用 CTM RL 的 linear orthogonal 初始化，以上 head 的 gain=1，bias=0。
- KB 保存 Controller+Actor，**不创建或保存未被训练的 KB Critic**。采样/评估 KB 只需要动作分布，Fisher 不需要 value。
- Active Critic 只接受当前阶段的 PPO value loss，每轮/每个下游 Progress 随 Active 重置；不参与 KL、EWC、侧向连接。

## 6. 双列与侧向适配器

每个 tick 固定顺序：

1. KB 用自己的旧 trace、同一 fmap、零 lateral 推进一 tick，得到 z_kb_new。
2. `lateral=tanh(gate)*Linear(512,512,bias=False)(LayerNorm(z_kb_new))`。
3. Active 用自己的旧 trace 与该 lateral 推进一 tick。

Adapter 的 Linear 使用 orthogonal(gain=1)，LayerNorm 默认参数，gate 为可学习标量，初始化 0。首个更新允许仅 gate 有非零梯度；gate 离开零点后线性层可获得梯度。

- Adapter 属于 Active，每次 Active reset 一起重新初始化；它不属于 KB，不被蒸馏为 KB 的一部分。
- 首次完成一次蒸馏之前 `kb_ready=False`，强制 lateral=0；第一次蒸馏完成后置 True，此后不再关闭。
- X/P 中 KB 整段 no_grad，且 eval；Active/Adapter 接受 PPO 梯度。KB 输出 detach 不阻断 Adapter 自身参数梯度。
- C 中教师是训练后的 Active+Adapter+其旧 KB 依赖的冻结快照；学生是待更新的当前 KB。教师旧 KB 与学生参数、state、buffers 不共享 storage。
- E 在 X/P/C 内固定，可共用一次视觉 forward 的结果；当 E 已版本更新，旧 fmap cache 必须失效。
- W 更新 E 时冻结所有控制器和 Adapter。采集用 E_old 的独立快照，不访问正在更新的 E。

### 7.1 Transition 与 PPOBatch

`Transition` 至少包含：obs、transition_next_obs、action、terminated、truncated、episode_start、episode_id、episode_step、task_key、encoder_version、world_model_version、transition_id。世界模型 replay 不保存 reward_ext，避免错误使用。

PPOBatch 为时间优先：obs `[L,B,3,84,84]`、actions/old_logprob/old_value/reward/advantages/returns `[L,B]`、episode_start/terminated/truncated bool `[L,B]`、rollout 起点的本列 states、bootstrap_values `[L,B]`。PPO 中 reward 由阶段决定，X 为 intrinsic、P 为 extrinsic；两者不可相加。

PolicyOutput.state 和 PPOBatch.initial_state 为显式带标签联合类型：单列使用 CTMState，双列使用 DualState(kb,active)。不得以虚构零KB凑双列接口；两种模式均按环境序列重放。PPOBatch还携带valid_mask `[L,B]`，用于精确预算尾批；padding不推进state且不参与GAE/均值。

### 7.2 SequenceBatch

- obs `[U+L,B,3,84,84]`；episode_start/valid_mask 同时间维；burnin_mask 前 U 为 True；loss_mask 仅有效的后 L 步。
- teacher_log_probs `[L,B,5]`，由冻结教师沿真实历史在采集时生成并保存；无需用短 burn-in 近似重建教师目标。
- 学生为每条窗口从自己的 learned initial state 开始，以前 U 个观察进行 no_grad burn-in，再 detach，后 L 步带梯度。
- 当真实 episode 历史不足 U 时在左侧 padding；padding 不推进任何 trace、不参与损失，第一真实观察正确 episode_start。
- 后 L 步允许跨 episode，遇到 episode_start 对相应槽位重置；时间不随机打散，只随机分组序列/环境。
- 教师行为始终由其自身完整 collect 历史决定；学生短 burn-in 是明确的截断近似，禁止描述为“精确恢复所有过去状态”。

### 7.3 FisherState

包含参数名→float32 同形张量 F、参数名→theta_star、completed_compressions、估计样本数、当前 stage_key、encoder_version。参数范围仅 KB Controller+Actor，包括初始 trace、两类 decay、Attention 与 NLM 参数；不包含 E/g/F/Adapter/Critic。

### 7.4 FisherSequenceBatch

独立于蒸馏SequenceBatch，包含obs/episode_start/valid_mask/burnin_mask以及actions `[U+L,B]` int64、score_mask `[U+L,B]` bool、transition_ids；不包含teacher target、reward、value或advantage。score_mask只能位于有效learning步，每个选中的transition_id恰出现一次。

## 8. 数据与接口失败行为

- 配置中的输入尺寸、动作数、head 维数、burn-in/tick 整除条件不满足时，在构建环境前报错。
- 数据泄漏检查、非有限 loss/gradient、阶段冻结检查失败时停止当前 run，写出错误与最近阶段 checkpoint；不自动改变算法参数重试。
- replay 中同任务但不同版本的 raw observation 可重编码；不同 task_key 禁止进入当前 W minibatch。
- 训练用 image hash、路径、状态坐标、任务名称、成功标签不能进入网络输入。评估指标允许读取环境信息，但不反传、不训练。
