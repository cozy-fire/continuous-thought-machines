# 五步序列权重：200张未见Maze测试

使用最终7000次更新的本地权重；T5/M40。测试地图为test中的固定200张，与训练地图内容哈希无重叠。两种模式使用相同地图和起点、确定性argmax、最多300步，教师只评分，不控制动作。

每5步重置：保留窗口完成5次学生动作及新观察，在第6/11/16…步前恢复可学习初始窗口。持续状态：只在episode开始恢复初始窗口，直到终止或300步。二者均为完整rollout，不是一次观察开环输出5动作。推理采用FP32 eager；与训练相同tick计算式，未修改权重。

两个模式都成功29张；仅每5步重置成功5张；仅全程保留成功3张。

轨迹一致率是各模式自己访问的全部有效决策的加权正确率；模式造成不同轨迹和不同分母，不能解释为同一状态集合上的分类差异。本归档仅保留汇总报告，原始轨迹与指标未纳入。

单模型seed，每图一集。CI反映固定测试面板内地图重采样的不确定性，不涵盖训练seed方差，不声称序列方式普遍优于单步方法。训练地图全起点五步一致率97.25%不能代替本测试闭环效果。

核验：21份模型/环境/教师源码与训练备份一致；权重SHA前后不变；两模式各200条完整终止轨迹；同一地图前5动作完全一致；累计计数与CSV匹配。
