# Teacher forcing 五步序列实验结论

训练已完成，累计13000次 optimizer.step，退出码0；完整备份验证通过，官方CLI确认实例已释放。

T5/M40，地图池5/10/20/40/80/160/320；80图1000更新，其余各2000。每更新100条五步序列，microbatch5，FP32。起点随机采样非终止训练状态，恢复可学习初始窗口；BFS教师动作推进地图，学生预测计算交叉熵（one-hot教师到学生KL）。五步内不重置、不detach，终止后mask；每microbatch汇总五步反传，20组累积按有效决策总数归一化，clip0.5，Adam更新一次。阶段保留Active/Adam，KB冻结、侧向关闭。

训练集五步一致率99.13%没有转化为较高的未见地图闭环成功率。与之前on-policy的17%/16%相比，本次为16.5%/13.5%；训练预算与最终地图池不同，单seed结果不能归因于teacher forcing一个变量。两种测试访问的状态不同，轨迹一致率不是相同状态集合上的分类对比。

四个共同失败案例为test/0/0.png至test/0/3.png，两模式均300步超时。重置模式反复往返，持续窗口模式出现撞墙停留；地图1持续模式288步无位移，地图3最终目标距离由70增至76。逐动作重放已核验BFS标签、位置、奖励和终止；本归档只保留这些结论，不保留轨迹、图片或动画。
