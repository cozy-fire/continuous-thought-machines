每次更新100条序列，microbatch5。起点随机取当前地图池全部非终止可通行状态，初始化一次M40窗口；学生逐步argmax动作推动真实地图状态，每步读取新观察及BFS标签，连续5次决策，各5 ticks，中间不重置、不detach。不是仅看起点一次输出5个动作。

每条序列汇总5步one-hot教师交叉熵（等价于教师到学生KL）；到达终点后mask。每组完成5步后backward，20组累计梯度按总有效决策数归一化，clip0.5后一次Adam更新。阶段保留Active/Adam及随机状态，KB冻结、侧向关闭。
